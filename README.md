# ReadCraft

Write a README the way you think — and see it look finished while you type.

ReadCraft is a quiet little workspace for README files and docs. Left side: your words. Right side: a live preview. No fuss, no account, no wait.

---

## What you can do

**Write freely**  
Type the whole document in one go, or build it section by section. Paste a huge file and keep working — the editor stays responsive.

**See it live**  
Headings, lists, tables, code blocks, checkboxes, quotes, badges, and links show up in the preview as you go.

**Drop in ready-made pieces**  
Need a title banner, features list, install steps, API table, or license blurb? Grab a section from the library and drop it in. Save your own snippets too.

**Math that actually looks like math**  
Write equations the way you’d write them in a paper. They render cleanly in the preview and in your PDF.

**Make it yours**  
Pick a look — warm parchment, dark ink, GitHub light/dark, bold yellow, or cool slate. Choose a typeface and editor size that feel right.

**Save without thinking**  
Your work auto-saves in the browser. Rename files, keep a short list of recent READMEs, and come back later.

**Take it with you**  
Copy the markdown, or download as Markdown, PDF, HTML, text, or JSON. PDF export shows progress so you’re never left wondering.

**Templates of your own**  
Like a README you’ve built? Save it as a template and reuse it next time.

---

## Who it’s for

Anyone who writes READMEs, project docs, or notes in Markdown — and wants the finished page in front of them while they write, not after.

---

## Try it

```bash
npm install
npm run dev
```

Open the link in your terminal, start typing, and watch the preview keep up.
